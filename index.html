Scheduled Jobs (Cron)

All jobs run on hermes-associate. The cron ticker is running (heartbeat confirmed) but zero jobs are currently configured. Everything below is new.

📬 Morning Email Triage
Daily · 7:30am ET
profile: hermes-associate
Scan unread/recent Gmail threads. Classify by urgency. Summarize each in 1–2 lines. Flag dates detected for proposed calendar events. Includes inbound action item detection (emails where Sam owes a response).
Implementation spec
  • Source: gmail search "is:unread OR newer_than:1d" --max 50
  • Classification tiers: Court/tribunal → ⚠️ Urgent · Opposing counsel → 🔴 High · Client → 🟡 Normal · Admin → ⚪ Low
  • Calendar proposals: Extract dates from email text, present as "Proposed Events" section. Never auto-create — Sam confirms with 👍 per event
  • Inbound action watch: Detect emails requiring Sam's action (requests, questions, documents to review). Thresholds: 2d ⚠️ / 5d 🔴 / 10d 🚨
  • Output format: Notion-aesthetic table, grouped by urgency, matter-specific emojis, clickable Gmail thread links (u/0), dates MM/DD/YYYY
  • Delivery: Desktop app notification
👁️ Follow-Up Tracker
Daily · 4:00pm ET
profile: hermes-associate
Track threads where a response is owed — outbound (Sam sent, no reply) and inbound (someone sent Sam something requiring action). Persistent state file with aging thresholds.
Implementation spec
  • State file: ~/.hermes/profiles/hermes-associate/data/follow-up-tracker.json
  • Scan window: All threads from last 60 days (sent + received)
  • Outbound detection: Letters to counsel, demand letters, requests for production, "please advise" / "kindly confirm" patterns, delivery-line formatted correspondence
  • Inbound detection: Court/tribunal emails, client questions, opposing counsel document requests, emails with embedded deadlines
  • Outbound aging: 3d 👀 Watching → 7d ⚠️ Stale → 14d 🔴 Overdue (suggest follow-up draft) → 30d 🚨 Critical
  • Inbound aging: 2d ⚠️ → 5d 🔴 → 10d 🚨
  • Resolution: Auto-resolves when reply detected. Manual snooze/dismiss commands supported
  • Afternoon run: Stale items only (short alert). Full context in morning triage + weekly review
💰 Business Expense Tracker
Friday · 4:00pm ET
profile: hermes-associate
Scan Gmail "Business Expenses" label, extract invoice/receipt data from email body + PDF attachments, append to Google Sheet. Deduplicates by message ID.
Implementation spec
  • Gmail label: Label_24 ("Business Expenses") — already exists with sub-labels CPD, Employment Matters
  • Google Sheet: "Business Expenses 2026" in Presvelos Law Google Workspace. One sheet per calendar year (Jan–Dec), rolls over in January
  • Columns: Date | Vendor | Description | Category | Pre-Tax | HST | Total | Payment Method | Source | Receipt # | Message ID
  • Category taxonomy: Legal Research / Subscriptions · Professional Dues & Insurance · Office / Rent / Utilities · Software / Technology · Courier / Postage / Filing Fees · Travel · Meals & Entertainment · Marketing / Business Development · Professional Development / CLE · Telecommunications · Office Supplies · Court Fees / Disbursements · Other
  • Receipt parsing: HTML body extraction (Stripe, Apple, Google receipts) + PDF attachment parsing via Docling for invoices
  • HST breakout: Extract pre-tax, HST/GST, and total separately for ITC recovery
  • Dedup: Gmail message ID stored in column K — skip already-logged messages
  • Script: ~/.hermes/profiles/hermes-associate/scripts/expense_tracker.py (written, ready to test)
Prerequisites
  • Enable Google Sheets API on project 714782241152
  • Create the Sheet and run initial backfill: --backfill --max 200
  • May need OAuth re-auth if Sheets scope wasn't included in original grant
